| Version | Supported          |

| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of ibuku seriously. If you discover a security vulnerability, please disclose it responsibly.

### How to Report

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email details to `mwakidenis@gmail.com` with the subject line `[SECURITY] ibuku vulnerability report`.
3. Include: affected version, steps to reproduce, impact assessment, and suggested remediation.

### What to Expect

- Acknowledgement within 72 hours.
- Status updates every 7 days until resolved.
- Public credit (if desired) in the release notes for the fixing version.

> [!CAUTION]
> Never commit secrets, API keys, or credentials to this repository. All security disclosures must be routed through the email channel above — public issues exposing vulnerabilities will be closed immediately.
